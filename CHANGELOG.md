# Changelog

## 0.2.1 — 14 September 2026

- Fixed the three-hour Türkiye/UTC display shift by explicitly marking stored UTC timestamps in API responses.
- Added regression assertions for timezone-qualified booking timestamps.

## 0.2.0 — 14 September 2026

- Redesigned the interface as a responsive AYBU-inspired portfolio concept.
- Added resource, active-booking and capacity dashboard statistics.
- Added a visible resource inventory with capacity information.
- Added reservation search and status filtering.
- Exposed the existing cancellation workflow in the browser interface.
- Added status badges, accessible labels and clearer success/error messages.
- Added default one-hour reservation times.
- Expanded the automated suite to five tests.

## 0.1.0 — 11 September 2026

- Added resource and booking APIs, conflict detection, cancellation and a basic browser interface.
